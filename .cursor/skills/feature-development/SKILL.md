# Feature development

Thin approval wrapper. For the full project-specific workflow, follow
`.cursor/skills/flutter-feature-development/SKILL.md`.

## Gates (do not skip)

1. Inspect `home`, `pubspec.yaml`, Mason brick, DI, and routes before editing.
2. Ask approval before `mason make`, bulk generation, overwrites, dependency
   changes, architecture changes, or build/env changes.
3. Do not copy `cart` / `profile` stubs.
4. Report files changed, checks run, and remaining risks.
