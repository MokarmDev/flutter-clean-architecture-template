# Code review

Thin approval wrapper. For the project-specific checklist, follow
`.cursor/skills/flutter-code-review/SKILL.md`.

## Gates (do not skip)

1. Review the diff, not only final files.
2. Order findings by severity (Critical / High / Medium / Low) with file references.
3. Do not edit files during a review.
4. Do not claim tests passed unless they were run and inspected.
